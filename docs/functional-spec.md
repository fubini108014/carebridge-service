# 🏥 陪診媒合平台：專案規格書 (Functional Spec)

## 一、 專案概述
[cite_start]本專案旨在建立一個基於 Line 生態系的「陪診服務媒合平台」 [cite: 1, 3][cite_start]。透過訂閱制門檻篩選高品質用戶，整合 **民眾**、**業務**、**診所** 三方資訊，實現預約、分潤、推播行銷之閉環商業模式 [cite: 3]。

| 角色 | 進入/驗證門檻 | 核心功能權限 |

| 一般民眾 | 加入 LINE 好友 | [cite_start]查看業務清單、查看診所介紹、接收平台一般公告 [cite: 5]。 |

## 三、 核心功能規格細節
### 1. 雙向確認預約系統
* [cite_start]**預付流程**：訂閱民眾選定業務時段後，需先支付一筆「媒合費」至平台 [cite: 8]。
* [cite_start]**30 分鐘決策期**：業務收到通知後，需在 30 分鐘內點擊「接受」或「拒絕」 [cite: 9]。
* [cite_start]**自動退款機制**：若業務拒絕或超時未回應，系統透過藍新 API 自動觸發全額退款 [cite: 11]。
* [cite_start]**強制緩衝規則**：系統強制執行 1 小時緩衝，預約前後 1 小時自動標記為不可預約 [cite: 172]。

### 2. 業務身分與佣金管理
* [cite_start]**身分驗證 (KYC)**：業務需於 LIFF 頁面上傳身分證、銀行存摺影本，後台人工審核通過後方可升級 [cite: 14]。
* [cite_start]**防截圖看板**：佣金看板頁面強制覆蓋含有「業務姓名/ID」之半透明動態浮水印 [cite: 18, 174]。

### 3. 成交回報與確認 (診所端)
* [cite_start]**掃碼驗證**：業務出示專屬 QR Code，診所櫃檯掃描後進入成交金額輸入頁面 [cite: 20, 174]。

### 4. 業務取消與扣點機制
* **業務取消已接單**：業務接單後仍可主動取消，民眾獲全額退款。
* **扣點記錄**：每次業務取消永久累積扣點，點數不恢復。
* **停權流程**：扣點達管理員設定之上限後，由管理員人工審核決定是否停權。
* **取消截止規則**：距服務時間多久內不可取消，由後台管理員設定。

### 5. 營運守則與法律配套
* [cite_start]**名義定義**：合約與系統內統一稱之為「陪診勞務媒合」與「市場推廣費」，以規避醫療轉介法律風險 [cite: 47]。
* [cite_start]**取消政策**：民眾 24 小時內取消預約，媒合費不予退還以補償業務損失 [cite: 114]。

## 四、 金流與分潤規劃
* [cite_start]**撥款邏輯**：按成交當時鎖定的比例拆分媒合費與分潤，不受診所事後調整比例影響 [cite: 35, 175]。
* [cite_start]**自動結算**：每月 5 號自動產出 PDF 格式之「市場推廣費結算單」 [cite: 117, 175]。
* **費率結構**：診所佣金比例由診所於後台自訂；媒合費由平台統一定價（金額待定）；平台從媒合費與診所佣金兩者皆抽成；業務所得佣金比例待定。
* **自動撥款**：每月固定日期透過藍新 API 自動撥款至業務帳戶，無最低提領門檻，撥款時間點待定。
* **錢包狀態**：Pending（待核銷）→ Available（可撥款）→ Paid（已撥款）。
