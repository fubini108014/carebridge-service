# 🏥 陪診媒合平台：專案規格書 (Functional Spec)

## 一、 專案概述
本專案旨在建立一個基於 Line 生態系的「陪診服務媒合平台」。透過訂閱制門檻篩選高品質用戶，整合 **民眾**、**業務**、**診所** 三方資訊，實現預約、分潤、推播行銷之閉環商業模式。

## 二、 客群角色與權限架構
| 角色 | 進入/驗證門檻 | 核心功能權限 |
| :--- | :--- | :--- |
| 一般民眾 | 加入 LINE 好友 | 查看業務清單、查看診所介紹、接收平台一般公告。 |
| 訂閱民眾 | 支付平台訂閱費 (吃到飽) | 開啟行事曆預約功能、追蹤特定診所並接收優惠推播。 |
| 驗證業務 | 身分審核 + 支付訂閱費 | 查看診所佣金表、管理接單行事曆、回報成交、管理分潤錢包。 |
| 合作診所 | 平台線下簽約 | 使用掃碼功能驗證成交資訊、申請發布推播訊息、查看對帳報表。 |
| 平台管理員 | 後台帳號（非 LINE） | KYC 審核、業務扣點/停權管理、手動調帳、推播訊息審核、費率與規則設定。 |

## 三、 核心功能規格細節
### 1. 雙向確認預約系統
* **預約流程**：訂閱民眾選定業務時段並送出預約申請，系統通知業務審核。
* **30 分鐘決策期（業務）**：業務收到 LINE Flex Message 通知，直接在聊天室點擊「接受」或「拒絕」按鈕；逾時視同拒絕。
* **付款時機**：業務接受後，系統向民眾發送 LINE 訊息，附上藍新金流付款連結，民眾點連結於外部瀏覽器完成付款，藍新 Webhook 回調後端更新預約狀態。
* **30 分鐘付款期限（民眾）**：民眾需在收到付款請求後 30 分鐘內完成付款；逾時未付則預約自動取消、時段釋放，並通知業務。
* **業務拒絕／超時**：不進入付款流程，預約直接取消，民眾收到通知。
* **退款情境**：預約成立後，若民眾或業務主動取消，系統透過藍新 API 觸發退款（退款規則詳見第 4、5 節）。
* **強制緩衝規則**：系統強制執行 1 小時緩衝，預約前後 1 小時自動標記為不可預約。

### 2. 業務身分與佣金管理
* **身分驗證 (KYC)**：業務需於 LIFF 頁面上傳身分證、銀行存摺影本，後台人工審核通過後方可升級。
* **防截圖看板**：佣金看板頁面強制覆蓋含有「業務姓名/ID」之半透明動態浮水印。

### 3. 成交回報與確認 (診所端)
* **掃碼驗證**：業務出示專屬 QR Code，診所櫃檯掃描後進入成交金額輸入頁面。
* **二次確認**：診所輸入成交金額後，系統推播通知業務於 LIFF 確認金額；業務需在 30 分鐘內確認，逾時系統自動確認該金額。若有爭議可事後向管理員申訴。

### 4. 業務取消與扣點機制
* **業務取消已接單**：業務可主動取消，需填寫取消理由，民眾獲全額退款。
* **扣點裁量**：系統不自動扣點，由管理員審閱取消理由後人工決定是否扣點。
* **扣點記錄**：扣點永久累積，點數不恢復。
* **停權流程**：扣點達管理員設定之上限後，由管理員人工審核決定是否停權。
* **取消截止規則**：距服務時間多久內不可取消，由後台管理員設定。

### 5. 營運守則與法律配套
* **名義定義**：合約與系統內統一稱之為「陪診勞務媒合」與「市場推廣費」，以規避醫療轉介法律風險。
* **民眾取消政策**：
  * 距服務時間 24 小時以上取消 → 媒合費全額退還。
  * 距服務時間 24 小時以內取消 → 媒合費不予退還。
* **業務取消政策**：業務取消時民眾媒合費全額退還；是否對業務扣點由管理員依取消理由裁量。

## 四、 金流與分潤規劃
* **撥款邏輯**：按成交當時鎖定的比例拆分媒合費與分潤，不受診所事後調整比例影響。
* **自動結算**：每月 5 號自動產出 PDF 格式之「市場推廣費結算單」。
* **費率結構**：診所佣金比例由診所於後台自訂；媒合費由平台統一定價（金額待定）；平台從媒合費與診所佣金兩者皆抽成；業務所得佣金比例待定。
* **自動撥款**：每月固定日期透過藍新 API 自動撥款至業務帳戶，無最低提領門檻，撥款時間點待定。
* **錢包狀態**：Pending（待核銷）→ Available（可撥款）→ Paid（已撥款）。
